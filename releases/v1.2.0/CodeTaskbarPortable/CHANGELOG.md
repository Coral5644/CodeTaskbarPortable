# 更新记录

## 1.2.0 — 2026-10-15

- Minecraft 窗口独立显示任务栏按钮，按启动命令的 config 路径生成开发区名称与 PID 标签。
- 支持网易开发启动器与中间脚本保留的配置参数；缺少可靠参数时标明未识别开发区并显示 PID。
- 仅在首次接管游戏窗口时查询本机 WMI，游戏原生窗口标题保持原样，不增加定时扫描。
- 托盘和状态说明覆盖 VS Code 与 Minecraft，修正托盘标题中的旧版本文字。
- 升级共享映射协议，避免与 Explorer 中保留的旧 DLL 使用不同结构；保留正常退出与控制进程退出恢复。
- 新增配置路径识别测试和真实窗口身份、标签调用、退出恢复核对工具。

## 1.1.1 — 2026-10-15

- 适配重启更新后的 Windows 26300.9711 / Taskbar.View.dll 2608.26001.200.0；核对匹配 PDB、接口 IID、函数与虚表位置，保留文件哈希和加载模块标识校验。
- 增加可选的当前用户登录计划任务安装脚本，无触发延迟、空闲或电池限制。
- 隐藏启动脚本等待任务栏就绪后立即启动，确认启用后退出，不新增常驻轮询；失败写入启动日志。
- 安装自启时备份旧配置并移除本工具同名 HKCU Run 项；原发布目录保持不变。

## 1.1.0 — 2026-10-15

- 以独立项目管理源码、图标、构建脚本和版本化发布包。
- 新增原创应用图标，嵌入 EXE 并用于系统托盘。
- 托盘菜单、提示、日志、状态文件和错误信息改为简体中文。
- 默认静默启动，仅驻留托盘，不显示主窗口或启动弹窗。
- 初始化失败时保留“未启用”托盘入口，允许查看日志和退出。
- 托盘支持查看运行状态、重新检查窗口、打开日志、打开目录和退出恢复；双击可查看状态。
- 保留任务栏组件校验、事件驱动更新、进程退出恢复和 Explorer 生命周期监控。

## 1.0.0 — 2026-10-15

- 首个免安装 EXE＋DLL 版本，只拆分 Code.exe 窗口并显示原生窗口标题。
- 已在 Windows 26300.9457 / Taskbar.View.dll 2607.28001.200.0 上验证。
- 原始发布包归档于 `releases/v1.0.0/`。
